# Визуализатор графа зависимостей

Практическая работа №2 по дисциплине
«Конфигурационное управление».

Вариант №16.

## Общее описание

Программа предназначена для анализа и визуализации
графа зависимостей npm-пакетов.

На первом этапе реализовано CLI-приложение
с настройкой через параметры командной строки.

## Параметры

- `--package` — имя анализируемого пакета;
- `--repository` — URL репозитория или путь
  к тестовому репозиторию;
- `--test-mode` — режим тестового репозитория;
- `--output` — имя PNG-файла графа;
- `--ascii-tree` — режим вывода ASCII-дерева;
- `--max-depth` — максимальная глубина анализа.

## Запуск

```powershell
.\run.bat --package react --repository https://registry.npmjs.org --test-mode false --output react_graph.png --ascii-tree true --max-depth 3

## Этап 2. Сбор данных

На втором этапе реализовано получение данных
о прямых зависимостях npm-пакетов.

Данные загружаются напрямую из npm-репозитория
без использования npm или сторонних библиотек
для получения зависимостей.

По умолчанию анализируется версия пакета,
указанная в теге `latest`.

### Пример запуска

```powershell
.\run.bat --package express --repository https://registry.npmjs.org --test-mode false --output express_graph.png --ascii-tree false --max-depth 3

## Этап 3. Основные операции

На третьем этапе реализовано построение
транзитивного графа зависимостей.

Для обхода графа используется алгоритм BFS
с рекурсивным переходом между уровнями.

Поддерживаются:

- ограничение максимальной глубины анализа;
- обработка циклических зависимостей;
- работа с тестовым репозиторием;
- чтение графа из текстового файла.

В тестовом репозитории пакеты обозначаются
заглавными латинскими буквами.

### Пример тестового репозитория

```text
A: B C
B: D
C: D E
D: A
E:
## Этап 4. Обратные зависимости

На четвертом этапе реализован режим анализа
обратных зависимостей.

Обратные зависимости показывают пакеты,
которые зависят от заданного пакета.

Для обхода обратного графа используется
алгоритм BFS из предыдущего этапа.

Для включения режима используется параметр:

`--reverse true`

### Пример запуска

```powershell
.\run.bat --package D --repository tests/data/graph_branch.txt --test-mode true --output graph.png --ascii-tree false --max-depth 3 --reverse true
## Этап 5. Визуализация

На пятом этапе реализована визуализация
графа зависимостей.

Программа:

- формирует текстовое описание графа
  на языке Graphviz DOT;
- сохраняет изображение графа в формате PNG;
- при параметре `--ascii-tree true`
  выводит зависимости в виде ASCII-дерева;
- корректно отображает циклические зависимости.

Для создания PNG используется программа
Graphviz `dot`.

### Пример запуска

```powershell
.\run.bat --package axios --repository https://registry.npmjs.org --test-mode false --output axios_graph.png --ascii-tree true --max-depth 1
